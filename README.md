# MeetingMind AI

## AI Meeting Memory Assistant

MeetingMind AI is an AI-powered meeting memory assistant that helps users remember important discussions, decisions, assigned tasks, and deadlines from meetings.

Instead of manually searching through lengthy meeting transcripts, users can upload a transcript and ask questions in natural language. The assistant retrieves relevant information from the meeting and provides accurate, context-aware responses.
